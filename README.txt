WAKEBOARD PERFORMANCE 2027 — Persönliche PWA

So nutzt du sie auf dem iPhone:
1. Lege die drei Dateien index.html, manifest.webmanifest und sw.js auf einen kleinen Webhost (z.B. GitHub Pages, Netlify, Cloudflare Pages oder eigener Webspace).
2. Öffne die URL in Safari auf dem iPhone.
3. Teilen -> Zum Home-Bildschirm.
4. Danach öffnet sie sich wie eine eigene App.

Wichtig: Die Trainingsdaten werden lokal im Browser auf dem Gerät gespeichert (localStorage). Sie verlassen das Gerät nicht, solange du die Dateien nicht um externe Dienste erweiterst.
